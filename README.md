# webos-userland

Stub libraries and headers for common propriertary LG WebOS libraries

## NetCast 4

`cmake --preset nc4` builds stubs for NetCast 4.x TVs instead, containing only the
APIs that exist there. See [docs/nc4.md](docs/nc4.md) for the API differences and
[examples/nc4](examples/nc4) for test programs.
